# 휴먼 하네스 v3 — 재설계안

> 시키는 대로만 하면 하루가 굴러가는 앱.
> 앱이 머리(계획·기억·판단)를 맡고, 사람은 손(지금 이 한 가지)만 맡는다.
> 몸에 익은 것부터 앱이 손을 뗀다.

---

## 1. 지금 앱이 틀린 이유

지금 앱은 **잘 사는 사람의 도구**다. 목표를 정하고, 완료 기준을 쓰고, 규칙을 만들고, 회고를 쓰라고 한다.
그런데 이건 전부 **실행 기능**(계획, 시작, 순서 정하기, 기억, 자기 점검)이 멀쩡해야 할 수 있는 일이다.

루틴이 무너진 사람, ADHD가 심한 사람, 기억력이 나쁜 사람이 정확히 못 하는 게 바로 그것이다.
그러니 지금 앱은 **가장 못 하는 일을 시켜 놓고 빈칸 앞에 세워 두는 앱**이다. 막막한 게 당연하다.

- 빈칸 → 무엇을 써야 할지 정하는 것 자체가 실행 기능이다.
- 모듈 7개 → 지금 어디로 가야 할지 고르는 것 자체가 실행 기능이다.
- "오늘이 끝났을 때 무엇이 되어 있으면 좋은 하루인가?" → 계획을 세울 수 있는 사람만 답할 수 있다.

## 2. "하네스"를 다시 정의한다

AI 하네스에서 모델은 **판단하지 않는다.** 하네스가 지시를 주고, 도구를 하나씩 쥐여 주고, 기억을 대신 들고 있고, 결과를 확인하고, 다음 할 일을 정한다. 모델은 지금 주어진 한 단계만 잘하면 된다.

사람에게 옮기면:

| AI 하네스 | 휴먼 하네스가 대신 하는 일 | 사람이 하는 일 |
|---|---|---|
| 시스템 프롬프트 | 기본 하루 틀을 앱이 깔아 둔다 | 고르기만 한다 |
| 에이전트 루프 | 지금 할 일 **하나**를 화면에 띄운다 | "했다"를 누른다 |
| 도구 호출 | 일을 2분짜리 단계로 쪼개서 하나씩 준다 | 그 단계만 한다 |
| 컨텍스트 관리 | 떠오른 걸 받아 두고, 나중에 앱이 먼저 물어본다 | 던져 두기만 한다 |
| 메모리 | 약속·마감·물건을 앱이 기억하고 때 맞춰 꺼낸다 | 기억하지 않는다 |
| 검증 루프 | 했는지 매번 확인하고 기록한다 | 탭 한 번 |
| 평가·튜닝 | 자꾸 실패하는 건 앱이 알아서 줄이고, 잘되는 건 늘린다 | 제안에 "좋아"만 누른다 |
| 가드레일 | 무리한 계획을 막는다 (하루 최대치, 최소 버전) | — |

한 문장으로: **휴먼 하네스 = 외장 전두엽.**
실행 기능을 앱이 빌려주고, 반복으로 그 기능이 사람 안에 자라면 앱은 빠진다.

## 3. 누구를 위한 앱인가

| 사람 | 실제로 무너지는 지점 | 하네스가 대신 하는 것 |
|---|---|---|
| 루틴이 망가진 사람 | 기상·식사·수면 시간이 매일 다름 | 하루를 지탱하는 "닻" 3개부터 깔아 준다 |
| 계획을 못 세우는 사람 | 빈 계획표 앞에서 얼어붙음 | 계획을 앱이 만든다. 사람은 고른다 |
| ADHD가 심한 사람 | 시작을 못 함, 시간 감각 없음, 딴 길로 샘 | 2분짜리 첫 단계, 눈에 보이는 시간, 하나만 보이는 화면 |
| 막 사는 사람 / 규칙적인 생활 경험이 없는 사람 | 뭐가 "정상적인 하루"인지 모름 | 기본 하루를 처방전처럼 준다 |
| 기억력이 나쁜 사람 | 약속, 할 일, 챙길 물건을 잊음 | 들은 순간 받아 적고, 때가 되면 먼저 꺼낸다 |
| 약속을 못 지키는 사람 | 늦게 출발, 날짜 착각 | 출발 시간을 거꾸로 계산해서 알려 준다 |

**공통점:** 의지가 없는 게 아니라 **판단과 기억을 할 여력이 없다.** 그러니 판단과 기억을 앱이 가져간다.

## 4. 설계 원칙

1. **화면엔 한 가지만.** 메인 화면은 대시보드가 아니라 "지금 할 것" 카드 한 장이다. 다음 것은 숨긴다.
2. **쓰게 하지 말고 고르게 한다.** 모든 입력은 탭 한두 번이면 끝난다. 글쓰기는 언제나 선택이다. 기본값이 늘 채워져 있다.
3. **명령형으로 말한다.** "물 한 컵 마시세요." 질문하지 않는다. 코치처럼 짧고 구체적으로.
4. **시작은 2분.** 모든 할 일에 "최소 버전"이 있다. 샤워 대신 "욕실에 들어가기", 청소 대신 "쓰레기 3개 버리기".
5. **실패해도 혼내지 않는다.** 연속 기록을 깨뜨리는 대신 "이틀 연속만 피하자". 무너진 날엔 "최소 하루" 모드가 있다. 언제든 "다시 시작" 버튼.
6. **앱이 먼저 묻는다.** 사용자가 기능을 찾아가지 않는다. 아침에, 저녁에, 약속 전에 앱이 먼저 체크인을 띄운다.
7. **하네스는 줄어든다.** 성장의 척도는 "앱 없이도 하게 된 것의 개수"다. 몸에 익은 것은 앱이 알림을 끊고 졸업시킨다.
8. **기기 밖으로 나가지 않는다.** 서버 없음, AI 없음, 로컬스토리지만. 계정도 없다.

## 5. 핵심 경험: 하루가 이렇게 굴러간다

### 처음 켰을 때 (2분 설정)
질문은 전부 탭으로 답한다.

1. "보통 몇 시에 일어나요?" → 시간 칩 (7시 / 8시 / 9시 / 10시 / 그 이후 / 들쭉날쭉)
2. "몇 시에 자고 싶어요?" → 시간 칩
3. "요즘 생활은 어때요?" → 4단계 (꽤 괜찮음 / 들쭉날쭉 / 많이 무너짐 / 아무것도 안 됨)
4. "제일 안 되는 것 1~2개" → 칩 (일어나기, 씻기, 끼니, 밖에 나가기, 집안일, 할 일 시작, 약속·마감, 잠들기)

→ 앱이 **시작 루틴**을 처방한다. 예: 많이 무너짐 + 일어나기·끼니 선택 시

```
오늘부터 이것 3개만 합니다.
 ☀ 9:00  일어나서 물 한 컵         (최소: 침대에서 일어나 앉기)
 🍚 13:00 뭐든 먹기                  (최소: 바나나 하나)
 🌙 1:00  폰 내려놓고 눕기            (최소: 불 끄기)
[시작하기]
```

### 아침 체크인 (30초)
앱을 처음 여는 순간 뜬다.

```
좋은 아침.
잠은?        [푹 잤다] [그럭저럭] [못 잤다]
기운은?      [괜찮다] [별로] [바닥]
오늘 정해진 일 → 오후 3시 치과 (앱이 기억함)
```
→ 기운이 바닥이면 자동으로 **최소 하루**: 닻 루틴의 최소 버전 + 약속만 남긴다.
→ 아니면 **보통 하루**: 닻 + 약속 + 할 일 상자에서 앱이 고른 1~2개.

### 낮: "지금" 카드
```
┌─────────────────────────────┐
│ 지금                 13:05  │
│                             │
│   🍚 뭐든 먹기               │
│   최소: 바나나 하나           │
│                             │
│ [했다]  [2분만 해볼게]  [나중에] │
│                             │
│ 다음: 14:20 치과 출발까지 75분 │
└─────────────────────────────┘
```
- **했다** → 체크, 다음 카드.
- **2분만 해볼게** → 단계별 진행 모드(아래)로 들어가 첫 단계만 보여 준다.
- **나중에** → 20분 뒤 / 1시간 뒤 / 오늘은 안 함. 하루에 미룬 횟수는 기록되고 저녁에 조정된다.
- 정해진 시간이 없는 빈 시간엔: "할 일 상자에서 하나 할래요?" 하고 앱이 하나를 골라서 내민다.

### 단계별 진행 모드 ("같이 하기")
일을 끝까지 하라고 하지 않는다. 한 단계씩 화면에 띄우고, 다 하면 다음 단계.

```
샤워 · 2/6
 수건 꺼내 두기
[다 했다]           ⏱ 1:12
그만할래요 (여기까지도 잘했어요)
```
- 자주 하는 일에는 앱이 기본 단계를 갖고 있다: 샤워, 설거지, 방 정리, 장보기, 외출 준비, 서류 처리, 빨래, 자기 전 정리.
- 직접 만든 일도 "첫 단계만 적기"를 하면 그것부터 시작한다.

### 기억 맡기기 (캡처 + 약속)
상단 ＋ 버튼, 어디서든.
- 떠오른 걸 그냥 적거나 말한다(받아쓰기는 키보드 마이크). 분류는 하지 않는다.
- 날짜·시간이 있으면 약속으로: 날짜 칩 + 시간 + "가는 데 걸리는 시간" 칩(10/20/30/60분).
- 앱이 **출발 시간**을 계산하고, 준비 시작 → 출발 → 도착 순서로 카드를 띄운다.
- 날짜 없는 건 할 일 상자로. **저녁 체크인 때 앱이 먼저 물어본다:** "이거 언제 할래요?" [내일] [이번 주] [언젠가] [버리기]

### 저녁 마감 (1분)
```
오늘 한 것    ✓ 물  ✓ 먹기  ✗ 눕기(어제)
못 한 이유는? [시간이 안 맞음] [너무 큼] [잊어버림] [하기 싫었음] [그냥]
내일 첫 할 일 → 앱 제안: "9:00 물 한 컵" [좋아] [바꿀래]
캡처 2개 정리하기 → 하나씩 [내일] [이번 주] [버리기]
```
이유 칩 하나가 다음 날의 조정에 쓰인다.

### 주간 점검 (일요일, 2분)
글을 쓰게 하지 않는다. 앱이 숫자를 보여 주고 **조정안을 제시**한다.

```
이번 주
 물 한 컵   6/7  → 거의 됐어요. 다음 주부터 하나 더 붙일까요? [좋아] [아직]
 뭐든 먹기  3/7  → 시간이 안 맞음 3번. 13시 → 12시로 옮길까요? [좋아] [그대로]
 눕기       1/7  → 너무 큰가 봐요. 최소 버전만 목표로 할까요? [좋아] [그대로]
```

## 6. 하네스가 스스로 고치는 규칙 (AI 없이, 정해진 규칙으로)

| 신호 | 앱의 조정 |
|---|---|
| 같은 닻을 3일 연속 놓침 + "너무 큼" | 목표를 최소 버전으로 낮춘다 |
| "시간이 안 맞음"이 3번 | 성공했던 시각 쪽으로 시간대를 옮기자고 제안 |
| "잊어버림"이 반복 | 알림을 하나 더, 또는 이미 하는 일 뒤에 붙이자고 제안 |
| 14일 중 12일 성공 | **레벨 업**: 다음 닻 하나를 제안 |
| 28일 중 25일 성공 | **졸업**: 알림을 끄고 "몸에 익은 것" 목록으로 |
| 하루 "나중에"가 5번 이상 | 다음 날 계획을 자동으로 줄인다 |
| 앱을 3일 이상 안 열음 | 돌아오면 혼내지 않고 "다시 시작" 화면 (최소 하루부터) |

사용자는 규칙을 직접 만들지 않는다. 제안을 받아들일지만 정한다.

## 7. 오래 쓰면 무엇이 바뀌나 (레벨)

| 단계 | 목표 | 앱이 하는 일 |
|---|---|---|
| 0. 바닥 다지기 | 기상·끼니·수면 닻 3개 | 거의 모든 걸 시킨다 |
| 1. 하루의 뼈대 | 씻기, 밖에 나가기 추가 | 단계별 진행을 자주 띄운다 |
| 2. 생활 관리 | 집안일, 장보기, 약속 지키기 | 기억과 출발 시간을 맡는다 |
| 3. 할 일 처리 | 하루 한 가지 "해야 하는 일" | 일을 쪼개 주고, 집중 타이머 |
| 4. 스스로 운영 | 계획을 직접 세워 본다 | 점점 묻기만 하고 시키지 않는다 |

**성장 지표 = 졸업한 습관 수.** 연속 일수가 아니라 "이제 앱 없이 하는 것"을 센다.
습관이 자동화되는 데 평균 두 달쯤 걸린다는 연구가 있다. 앱은 그 기간 동안 대신 기억하고 대신 시키는 비계(발판)다.

## 8. 남길 것 / 합칠 것 / 버릴 것

| 지금 기능 | 결정 | 이유 |
|---|---|---|
| 오늘 (한 문장, 3가지, if-then, 종료) | **재구성** → 아침·저녁 체크인 + 지금 카드 | 빈칸 대신 체크인과 제안 |
| 집중 세션 | **합침** → 단계별 진행 모드 안의 타이머 | 목표·완료 기준 쓰기는 대상 사용자에게 너무 무겁다 |
| 캡처 | **유지·강화** → 기억 맡기기 (약속, 출발 시간, 저녁에 앱이 정리 질문) | 핵심 기능 |
| 리듬 (에너지, 수면, 습관) | **흡수** → 에너지·수면은 아침 체크인, 습관은 닻 루틴 | 따로 찾아갈 화면이 필요 없다 |
| 매뉴얼 (규칙) | **대체** → 앱의 자동 조정 + 졸업 목록 | 사용자가 규칙을 만들 필요가 없다 |
| 회고 | **대체** → 주간 점검 (숫자 + 조정 제안, 탭으로 수락) | 글쓰기 회고는 버린다 |
| 생각 도구 (프리모템, 5 Whys, 결정 매트릭스…) | **버림** | 대상 사용자에게 맞지 않는다. 레벨 4 이후에 다시 생각 |
| 모듈 켜기/끄기 | **버림** | 레벨이 그 역할을 한다 |

## 9. 화면 구조

하단 탭 3개 + 어디서든 ＋.

```
[ 지금 ]   [ 하루 ]   [ 나 ]          ＋ 기억 맡기기
```

- **지금**: 체크인이 필요하면 체크인, 아니면 "지금 할 것" 카드 한 장. 앱의 90%는 여기서 끝난다.
- **하루**: 오늘 타임라인 (닻, 약속, 출발 시간, 고른 할 일). 현재 시각 선이 지나간다. 시간 감각이 없는 사람에게 남은 시간을 보여 준다. 내일 보기, 할 일 상자도 여기서.
- **나**: 레벨, 이번 주 숫자, 몸에 익은 것(졸업), 루틴 손보기, 알림·캘린더 설정, 백업.

## 10. 알림 문제와 해법

서버 없는 웹 앱은 앱을 닫으면 알림을 못 보낸다. 대상 사용자에게 알림은 생명줄이다. 그래서:

1. **폰 캘린더에 맡긴다.** 닻 루틴과 약속을 `.ics` 파일로 내보내 휴대폰 캘린더에 구독/가져오기 하게 한다. 캘린더 알림은 앱이 닫혀 있어도 확실히 울린다. 서버가 필요 없다. 루틴이 바뀌면 "캘린더 다시 내보내기"를 안내한다.
2. **앱이 열려 있으면** 지금처럼 로컬 알림 + 소리.
3. **앱을 여는 순간이 곧 알림이다.** 열면 무조건 "지금" 카드가 뜬다. 첫 설정에서 홈 화면 첫 줄에 앱을 두라고 안내한다.

## 11. 데이터

- 로컬스토리지, 백업은 JSON 그대로. v3는 새로 시작한다. v2에서는 활성 습관(→ 닻)과 미처리 캡처(→ 할 일 상자)만 옮기고, 집중 세션·생각 도구·회고·규칙 기록은 버린다.
- 새 데이터: `anchors`(시간대, 최소 버전, 단계, 레벨, 상태), `items`(약속·할 일, 날짜, 소요·이동 시간), `checkins`(아침·저녁 응답), `outcomes`(하루별 했다·미룸·못함 + 이유), `adjustments`(앱의 제안과 수락 여부), `templates`(단계별 진행 목록).

## 12. 하지 않는 것

- 의료 서비스가 아니다. ADHD나 우울로 일상이 무너졌다면 진료가 먼저이고, 이 앱은 그 옆에서 하루를 받쳐 주는 도구다. 설정 첫 화면과 "나" 화면에 한 줄로 안내한다.
- 수치심을 쓰지 않는다. 빨간 X, 깨진 연속 기록, "실패" 같은 말 없음.
- 사용자에게 시스템을 설계하라고 하지 않는다. 고급 설정은 레벨 4에서만 열린다.
- 게임처럼 만들지 않는다. 포인트·배지 대신 "몸에 익은 것" 목록 하나.

## 13. 구현 순서 제안

1. **뼈대**: 첫 설정(질문 4개) → 시작 루틴 처방 → "지금" 카드 → 저녁 마감. 이것만으로 하루가 굴러가야 한다.
2. **기억 맡기기**: ＋ 캡처, 약속 + 출발 시간, 저녁의 정리 질문.
3. **단계별 진행 모드**와 기본 단계 템플릿.
4. **하루 타임라인**, 아침 체크인의 최소 하루 / 보통 하루.
5. **자동 조정 규칙**과 주간 점검, 레벨·졸업.
6. **캘린더(.ics) 내보내기.**

각 단계가 끝날 때마다 실제로 하루를 써 보고 다음으로 간다.
