# 휴먼 하네스

같은 AI 모델이라도 하네스(지시, 도구, 메모리, 검증 루프)를 어떻게 짜느냐에 따라 성능이 크게 달라진다. 이 앱은 그 구조를 사람에게 옮긴 개인 운영 시스템이다. 화면 하나가 하네스의 층 하나다.

| AI 하네스 | 화면 | 하는 일 |
|---|---|---|
| 시스템 프롬프트 | 오늘 | 오늘의 한 문장, 가장 중요한 3가지, if-then 계획, 하루 종료 의식 |
| 에이전트 루프 | 집중 | 목표 → 완료 기준 → 첫 행동 → 타이머 → 기준 대비 검증 → 다음 단계 메모 |
| 컨텍스트 관리 | 캡처 | 어디서든 ⌘K로 생각을 꺼내 두고, 나중에 오늘 / 나중에 / 아이디어로 분류 |
| 도구 | 생각 | 프리모템, 5 Whys, 브레인스토밍, 제1원리, 결정 매트릭스 |
| 리소스 관리 | 리듬 | 에너지 체크인으로 피크 시간 찾기, 수면·움직임, 아주 작은 습관 |
| 메모리 (CLAUDE.md) | 매뉴얼 | 경험에서 배운 규칙. 집중 세션 시작 때 보이고, 몸에 익으면 졸업 |
| 평가 루프 | 회고 | 주간 측정값을 보고, 하네스를 바꿀 한 가지를 정해 매뉴얼 규칙으로 |

## 루프가 이어지는 방식

- 집중 세션을 마치며 남긴 **다음 단계 메모**는 다음 세션 계획 화면 맨 위에 뜬다.
- 세션의 **교훈**과 회고의 **바꿀 한 가지**는 매뉴얼 규칙이 된다.
- 활성 규칙은 **세션 시작 전**과 **오늘 화면**에 보인다.
- 하루 종료 때 적은 **내일의 첫 행동**은 다음 날 오늘 화면 맨 위에 뜬다.
- 세션 중 막힌 이유는 **회고 화면**에 모여서 보인다.

## 설계 원칙

1. **최소한으로.** 오늘의 일은 3개까지, 활성 규칙은 7개까지.
2. **스스로 고른다.** 안 쓰는 모듈은 설정에서 끈다.
3. **피드백은 빠르게.** 세션마다 시작할 때 정한 기준으로 결과를 확인한다.
4. **점점 줄인다.** 몸에 익은 규칙과 습관은 졸업시킨다. 하네스는 줄어들어야 한다.

## 실행

빌드 과정이 없다. 정적 파일 서버로 띄우면 된다.

```bash
python3 -m http.server 5173
```

브라우저에서 <http://localhost:5173> 을 연다. 휴대폰에서는 같은 와이파이에서 컴퓨터 IP로 접속하거나, 정적 호스팅(GitHub Pages, Netlify 등)에 올린 뒤 "홈 화면에 추가"하면 앱처럼 쓸 수 있다.

## 데이터

모든 기록은 브라우저의 localStorage에만 저장된다. 서버로 보내지 않는다. 설정 화면에서 JSON으로 백업하고 복원할 수 있다.

## 구조

```
index.html            앱 셸 (상단바, 하단 탭, 캡처 시트)
styles.css            디자인 토큰, 라이트/다크 모드
js/store.js           단일 저장소, 모든 모듈이 공유
js/ui.js              DOM 헬퍼와 공용 컴포넌트
js/app.js             라우터, 전역 캡처, 세션 타이머
js/modules/*.js       화면 하나 = 하네스 층 하나
sw.js                 오프라인 지원 (네트워크 우선)
```
